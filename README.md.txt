## Descripción del Hito
En este hito desarrollamos un sistema de inteligencia artificial para personajes no jugables, que incluye las funciones de patrullaje, detección de jugador y persecución. Se implementaron diferentes estados y transiciones, optimizando la respuesta de los NPCs ante distintos estímulos del entorno. Además, se realizaron pruebas de comportamiento para asegurar una integración fluida con el resto de los componentes del proyecto.

---

## Reflexión del Estudio

**Sinergia y Fricción:**  
Como grupo, consideramos que el mayor beneficio de trabajar en equipo fue la posibilidad de combinar distintas perspectivas para resolver problemas técnicos y mejorar el diseño del comportamiento de la IA. El principal desafío estuvo en la coordinación de tareas y el control de versiones, lo cual solucionamos mediante una mejor comunicación y revisión conjunta del código antes de cada integración.

**El Alma de la Máquina:**  
El parámetro que identificamos como más determinante para lograr una IA más realista fue el *detectionRadius*. Este valor influye directamente en la capacidad de respuesta del personaje ante la presencia del jugador. También comprobamos que el equilibrio entre *detectionRadius* y *loseSightRadius* es esencial para que el comportamiento del enemigo resulte coherente y convincente dentro del entorno de juego.
